# 更新安装体验交接（v1.1.1）

日期：2026-09-28
基线提交：`3fd166a`，`main`

## 用户意图与原实现

用户希望托盘“检查更新”下方的状态文字在发现新版时变成可点击的“安装”；设置增加“允许自动安装更新”，并希望自动更新尽量无感、无打扰。

原实现会在启动 15 秒后和每 12 小时自动检查。发现新版时发 `update_available` 事件；安装版在用户点击安装后调用 Tauri updater 的 `download_and_install`，便携版下载已签名 ZIP，再由独立助手在退出后替换 EXE。原安装失败会取走待安装对象，重试须重新检查。

Tauri 官方文档和本机 `tauri-plugin-updater` 源码确认：Windows 调用 `Update.install` 后会启动安装程序并退出应用；默认 `passive` 安装模式可能显示进度界面。`quiet` 模式也不能消除提权需要，且没有进度反馈。参考：https://v2.tauri.app/plugin/updater/ 。因此这里的“无打扰”指运行中只下载和验签，不因自动检查突然关闭；不能承诺安装过程完全不可见。

## 本轮实现

- 托盘状态行在发现新版时直接显示“发现 X 版，点击安装”；安装失败后可在原位置重试。自动下载完成后显示“X 版已就绪，点击立即安装”，也可不操作，等正常退出时安装。中、英、繁文案同步。
- 设置增加默认关闭的“允许自动安装更新”。启用时自动开启检查；关闭自动检查时同步关闭自动安装。应用运行期间后台下载并由 Tauri updater 验签，把已验证字节保存在本进程内存；在 Tauri 正常退出事件中启动安装，安装版禁止安装后自动重启。用户主动点击安装仍立即执行。
- 自动下载失败时保留已发现版本和手动安装入口；安装尝试失败时也保留待安装对象，可以直接重试。重复自动检查同一版本不会重复下载已准备的包；关闭自动安装会清除内存中的包。
- 便携版从已验签 ZIP 同时暂存主程序和新版替换助手。退出后由新版助手替换主程序并更新旧助手；自动更新不重新启动悬浮窗，手动安装维持重启和故障回滚。这样从旧便携版升级后，未来更新也能使用新版助手协议。
- README 中、英文同步说明行为与限制。

## 边界与待验证事项

- 已验证：前端 42 项测试、前端生产构建、Rust 42 项测试和本轮 diff 检查均通过。全仓 `cargo fmt --check` 因仓库原有的大量格式差异未通过，本轮没有对无关文件批量格式化。
- 尚未用真实签名新版包分别实测 Windows NSIS、MSI 和便携版的升级、退出、重启、提权与失败恢复。发布前需做这些烟雾测试。
- 已验证包只保存在当前进程内存中。如果进程崩溃、系统强制关机，或者下载未完成便退出，下一次启动会重新检查和下载；这避免缓存文件被替换后绕过签名校验。正常退出安装失败时，当前实现只写标准错误日志，下次启动后会重新检查。
- Windows 安装器的进度窗口和 UAC 提示由安装技术决定。安装版当前仍使用 Tauri 默认 `passive`；如希望进一步减少安装界面，需要先确认 NSIS/MSI 的实际发布形态与提权模型，不能仅靠前端选项保证“完全静默”。
