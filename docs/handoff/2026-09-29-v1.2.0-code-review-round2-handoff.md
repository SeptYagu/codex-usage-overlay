1. **折叠后重定位失败会留下与真实状态不一致的 dock 状态**：`drag_ended`（`src-tauri/src/dock.rs:802-825`）现在只 `eprintln!` 记录 `set_size`/`set_position` 失败，随后仍以 `finish_drag(edge)` / `save_docked(edge)` 广播“已贴边折叠”。旧实现（`git show 998a558:src-tauri/src/dock.rs`）在 `apply_pill` 失败时会退回 `finish_drag(None)` / `save_docked(None)`。**怀疑依据**：窗口被销毁或 DPI 切换瞬间的 `set_size`/`set_position` 失败会留下后端认定折叠、窗口实际未折叠的分歧态。**缺少的证据**：该分支的实机复现（无 GUI 无法触发）。**说明**：该行为由 `998a558` 引入、第 1 轮已审并于本轮**未改动**，按多轮复查防漂移规则不计为本轮缺陷，仅记录待观察。**建议**：实机验证时打开日志观察该 `eprintln!` 是否出现；若出现，恢复“落盘失败即退回未折叠”的对称处理。
2. **保护期内瞬时失焦 + `set_focus` 始终失败仍会在到期时 hide**（第 1 轮已记，本轮未变）：`tray.rs:141-149` 的守卫 `pending_blur && !is_focused` 属规定行为，只能在实机（开启鼠标穿透 + 另一前台窗口保持活动）判定。

**未验证项（受环境限制）**
