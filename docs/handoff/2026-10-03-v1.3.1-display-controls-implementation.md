## Delivered scope

Phases 2–4 are implemented as the display-only path. Both preferences default to true in Rust and TypeScript, legacy settings retain other preferences, and patches require booleans. The three-language settings UI keeps 5H, Credit and Burn Rate controls independent.

Expanded and collapsed views share one visible-quota list. Hidden Burn Rate has no span or placeholder; hidden 5H has no group, separator, bar or accessible label. The Weekly-only pill retains the original interaction host and 9px track thickness, with its single track centered on all four edges.

Tray presentation takes settings, optional usage and an explicit Pending/Success/Error status. Startup, the real refresh success/failure pipeline and settings patches share the same renderer/effect boundary. Weekly uses the outer-sized ring when 5H is hidden, including unavailable startup/error data. Display changes repaint from the allowed cache/status without a new fetch. Failure preserves cached usage and settings changes preserve its localized error tooltip. The effect sink also fixes unsafe UTF-8 tooltip truncation.

The production entry tests inject only fetch/native effects; they execute the real refresh guard, raw acceptance, estimator save, successful cache update and failed-read transition. They warm real crossing history and verify display patches preserve history bytes, cached DTOs, polling cadence and reset-notification preferences. Windows unit tests request Common Controls v6 in their own linker directives because the native effect paths import TaskDialogIndirect; application/updater manifest handling is unchanged.

Geometry invalidation includes both new preferences. Provisional sizing accepts the complete settings composition and remains no smaller than the existing pill. Edge measurements established grouped height 69px and a Credit increment near 100px including spacing. The conservative budgets are 140px per quota with rates / 100px without rates, 100px for Credit, grouped height 70px, and stacks extra width 40px / height 100px. The existing frontend measurement is authoritative for final sizing.

## Implementation review fixes — 2026-10-03

Review of `d280d7f` identified collapsed-pill movement on display changes (P2) and undersized countdown-only expansion budgets for 100% readings (P3).

- Collapsed repositioning now retains the session's pill centre instead of reconstructing it from the saved expanded position and provisional capsule dimensions. It resolves the work area from that centre, clamps the actual pill, and records the resulting centre after a successful native write. The current pill centre is the fallback when no session anchor exists.

- Verification: 86 frontend tests, 125 Rust tests, production build, locked Cargo check, and 406 offline Edge cases passed. Browser QA now runs both normal and 100% quota fixtures through the full composition/language/layout/scale matrix.
