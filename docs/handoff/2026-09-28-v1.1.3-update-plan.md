# 1.1.3 更新计划：设置窗口尺寸自由调整/持久化与版本号全景展示

日期：2026-09-28
发布基线：`v1.1.2` (`4d58e94`)；目标版本：`v1.1.3`。

---

## 一、需求背景与目标

本版本聚焦于用户在日常使用中反馈强烈的两类高频体验痛点：
1. **设置窗口尺寸不可调节与无记忆**：
   - 原先设置窗口被硬编码锁死宽度（`minWidth: 380, maxWidth: 380`），单列内容狭窄拥挤，且每次打开不居中、窗口大小与移动位置无法跨进程持久化；
   - 目标：彻底解除宽度锁死，允许用户自由调整宽高（设置合理的最小安全尺寸 `380×400`），并在用户移动或缩放后自动持久化落盘，重启后能在可用屏幕工作区内精准、安全地恢复；无历史记录时默认使用更舒适的宽敞尺寸（`480×660`）并居中打开。
2. **软件版本号缺乏直观展示**：
   - 系统托盘菜单中的“检查更新”未标注当前安装的客户端版本号，用户无法获知正在运行的版本；
   - 设置窗口右上角胶囊徽标原先硬编码显示静态占位符 `Tauri v2`；
   - 目标：在托盘菜单的“检查更新”后追加 `(当前版本: v{version})`（对齐中、英、繁三语），并将设置页右上角的徽标替换为真实的客户端版本号（如 `v1.1.3`）。

## 二、详细改动方案与实现设计

### 1. 设置窗口尺寸解除锁死与自适应布局
- **窗口配置调整** (`src-tauri/tauri.conf.json` 与 `src-tauri/src/tray.rs`)：
  - 默认尺寸由 `380×560` 提升至初始推荐 `480×660`；
  - 移除 `minWidth == maxWidth == 380` 的宽度锁死，设置安全弹性范围：
    - `min_inner_size(380.0, 400.0)`：确保表单控件和文字不会因过度缩小而被遮挡；
    - `max_inner_size`：设为宽松上限（如 `1600.0, 1600.0`）或由显示器工作区自动约束；
    - `resizable: true`，允许自由拉伸窗口边缘与四角。
- **前端弹性排版** (`src/components/SettingsView.tsx`)：
  - 外层容器增加 `overflow-x-hidden` 确保无破坏性横向滚动条；
  - 内部配置块使用响应式与流式布局，在窗口被拉宽时两端对齐自然延展，保持清爽视觉。

### 2. 设置窗口位置与大小的持久化记忆与安全恢复
- **存储结构** (`src-tauri/src/config.rs`)：
  - 新增持久化文件 `settings-window-geometry.json`，存储逻辑坐标与尺寸：
    ```rust
    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct SettingsWindowGeometry {
        pub x: f64,
        pub y: f64,
        pub width: f64,
        pub height: f64,
    }
    ```
- **自动保存时机** (`src-tauri/src/lib.rs`)：
  - 在 `on_window_event` 拦截到 `settings` 窗口的 `WindowEvent::CloseRequested`（即用户点击关闭按钮隐藏窗口）时，读取当前逻辑坐标与逻辑尺寸并异步写入 JSON 文件。
- **安全恢复与多屏幕校验** (`src-tauri/src/tray.rs`)：
  - `open_settings_window` 打开窗口时：
    1. 若存在已保存的历史几何数据：
       - 枚举系统所有可用显示器（`app.available_monitors()`）；
       - 校验目标矩形是否至少有一部分落在某一真实显示器工作区内；
       - 若屏幕存在（正常情况），将窗口应用保存的尺寸与位置并夹紧（clamp）在对应工作区内；
       - 若屏幕已断开（例如外接显示器拔出，落点落在虚空），自动回退到主屏居中并应用默认 `480×660`，防止“幽灵窗口”；
    2. 若无历史数据（首次启动）：
       - 赋予默认尺寸 `480×660`，并显式调用 `window.center()` 居中在主屏。

### 3. 系统托盘菜单版本号展示
- **多语言键位扩展** (`src/i18n.ts`)：
  - `zh-CN`: `menuCheckUpdates: "检查更新 (当前版本: v{{version}})"`
  - `zh-Hant`: `menuCheckUpdates: "檢查更新 (目前版本: v{{version}})"`
  - `en-US`: `menuCheckUpdates: "Check for Updates (v{{version}})"`
- **托盘渲染逻辑** (`src/components/TrayMenuView.tsx`)：
  - 引入统一的版本常量/助手 `APP_VERSION`；
  - 传入参数：`t('menuCheckUpdates', { version: APP_VERSION })`；
  - 依托原有 `measureMenu()` 自动重算托盘弹出窗口尺寸，保证扩展文本不折行、不遮挡。

### 4. 设置页右上角徽章替换
- **组件更新** (`src/components/SettingsView.tsx`)：
  - 将原静态 `<span ...>Tauri v2</span>` 替换为 `<span ...>v{APP_VERSION}</span>`；
  - 保留原有优雅的青色圆角药丸徽章样式 (`rounded-full bg-cyan-100 dark:bg-cyan-950 text-cyan-700 dark:text-cyan-300 font-mono`)。

### 5. 版本号统一升级为 1.1.3
- 发布准备时将以下 5 处配置文件版本号精准同步为 `1.1.3`：
  - `package.json`
  - `package-lock.json`
  - `src-tauri/Cargo.toml`
  - `src-tauri/Cargo.lock`
  - `src-tauri/tauri.conf.json`
