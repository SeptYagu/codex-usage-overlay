# DSH 订阅额度与主动连接

**DSH 与本机 Codex 是独立来源。没有插件额度时显示错误，不回退到本机读数。暂停仍是协作式请求，不是强制停止。**

本页描述主动连接实现；旧 `v1.6.0-preview.1` 至 `preview.3` 只提供手工安装/连接，不能据此认定旧安装已支持自动接入。自动连接和额度读取不需要用户安装 companion 或手工配对；保护目标仍须明确选择。

## 开始使用

1. 打开已经登录 Codex 订阅插件的 DSH Desktop。
2. 在「来源设置」中选择 **DSH**，保持该来源的监控开启。后台主动寻找 Desktop，必要时经其随附的官方 CLI 自动配置随包适配层；浮窗显示其他来源时也会继续接入和监控。
3. 等待“正在配置 / 等待热加载 / 正在认证”结束。状态变为已连接后，读取**订阅插件当前活动账户**的额度；不用粘贴 URL、token 或发现文件。
4. 如需耗尽保护，在保护目标中明确选择普通 DSH 会话，再开启保护。只想看额度，不需要绑定会话。

默认 Desktop 支持热加载时无需重启。官方 CLI 安装成功并不等于连通；只有发现记录、认证握手和订阅读取均通过，才能得到实际读数。若热加载被禁用或 Host 报告需要重启，按界面提示安全重启 DSH；浮窗不会自动关闭或杀死 DSH，也不会另起一个 Host。

自动配置仅支持 Windows、默认 `.dsh/profiles/desktop` 和运行中 Desktop 自带的官方 CLI。自定义 home/profile、非 Windows 或无法确定安装位置时，不猜测路径；可重试、使用兼容连接入口，或等待支持。没有运行中的 Desktop 时保持等待，稍后打开可继续发现。

## 自动选择与重启

- 只有一个通过认证且身份合格的实例时自动连接；多个实例不按文件名、修改时间或列表顺序任选第一个。
- 保存公开 profile 目录的 SHA-256 标识以跨重启找回同一 profile；不保存或显示原目录，不把此标识当认证凭据。仍用专用本机桥令牌认证。
- 发现记录保留每次运行的实例 UUID。重启后同一 profile 可重连，但旧暂停会话绑定失效，必须重新选择；绝不把旧 session ID 自动套到新实例。
- 断开是主动操作，不会立即被后台自动连回；点击重试可重新启动发现。
- 兼容的手工连接只用于自定义配置或故障排查，不是默认流程的前置步骤。插件显式禁用时不擅自重新启用。

活动账户可能随 DSH 内用户切换而改变。读取必须验证目标账户就是插件活动账户，不能显示“选了 A、实际拿到 B”的数值。来源切换、断开或认证变化会清理旧显示和取消旧请求，不允许迟到结果覆盖新来源。历史按运行实例和账户隔离。

## 耗尽保护

DSH 两个阈值与本机 Codex 分开设置，默认都是 `0%`。开启保护且新鲜、已验证的读数达到任一阈值时：

- 只检查所选**普通、正在运行的会话**；不批量控制其他会话、团队成员或后台任务。
- 只发送固定文案“暂停”的 `session.steer`，每个低额度窗口只发送一次。
- 回复“已接收”只表示协作请求进入 steer 队列，不证明模型已经暂停；模型可能继续当前工具或忽略指令。
- 不自动恢复，不创建“继续”定时任务，不调用本机 Codex 暂停桥。DSH 内置额度恢复等待是另一机制。
- 保护关闭、来源/账户/实例改变、断开或手工目标失效后，未发出的操作必须取消。重启不会沿用旧目标。

## 本机安全边界

后台用 Desktop 官方 CLI 安装**内嵌、精确字节校验**的无依赖 Host 适配包，开启 `--offline`、`--ignore-scripts`，使用官方 manifest writer 锁和 profile HMR。不手改 ASAR、订阅插件、运行中 manifest 或安装锁；不读取 OAuth、浏览器 Cookie、DSH 签名密钥或本机 Codex auth/log。

适配层只开放四种 RPC：订阅状态、订阅额度、普通会话列表、固定暂停 steer。它创建只绑定 `127.0.0.1` 的临时端口，以随机专用 Bearer 令牌认证；拒绝浏览器 Origin、重复认证头和非白名单方法，不提供 CORS。发现记录和暂存安装目录限制为当前用户及 SYSTEM 可写，路径中的链接或不安全权限会导致失败。

不会把桥令牌、RPC 原始响应、CLI 输出或 OAuth 写进设置、历史和日志。设置只保存实例/profile/账户/会话标识。非预期参数、多个不确定实例和不安全安装路径都拒绝自动处理。

## 验证与故障排查

先看状态区，再用“重试自动连接”。不要反复点手工连接或把本机 Codex 的百分比当成成功证据。

| 状态 | 含义与处理 |
| --- | --- |
| 等待 Desktop | 打开 DSH，保持 DSH 监控开启；不要另建 Host |
| 正在配置 | 正在执行官方本地安装事务，不要删除 writer 锁 |
| 等待热加载 | CLI 已结束，尚未收到可认证桥；如提示需要重启，再安全重启 |
| 多实例不确定 | 明确选择目标；不允许后台任取实例 |
| 订阅未登录或额度不可用 | 在 DSH 订阅插件中检查活动账户；不会借用本机账号 |
| 连接失效 | 会话绑定已清理，重连后重新选择保护目标 |

隔离安装验证可运行：

```powershell
$desktop = @(Get-CimInstance Win32_Process -Filter "Name = 'DeepSeek Harness.exe'" |
    ForEach-Object { $_.ExecutablePath } | Where-Object { $_ } | Sort-Object -Unique)
if ($desktop.Count -ne 1) { throw '请只保留一个可识别的 DSH Desktop 安装运行' }
.\scripts\Test-DshDesktopSetup.ps1 -DesktopExecutable $desktop[0]
```

此脚本只在仓库忽略的测试目录创建临时独立 home，调用实际官方 CLI，并验证依赖和 bundle 自动选择；不修改真实 profile、不启动 Host、不读取账户。它**不证明**真实 Host 热加载、订阅读数或暂停成功。这些必须分别有实机证据；不以单元测试数或 CLI exit 0 代替。
