# Codex Usage Overlay v1.5.1

This release fixes live Claude reading, which stopped about eight hours after signing in to the terminal `claude` CLI.

## Fixed

- Expired Claude CLI logins are renewed again. v1.5.0 ran `claude auth status` for this, but that command only reports the stored login and does not renew it, so live reading kept showing the last reading from before the login expired.
- The overlay now runs `claude plugin list`, then `claude doctor` if the login is still expired, at most every ten minutes and only while live reading fails with an expired login. Both make Claude Code renew its own login without starting a session or using quota. The overlay still never writes the credentials.
- If Claude Code cannot renew the login (for example, after signing out on another device), Claude Code clears the stored login. Sign in again with `claude` → `/login`.

## Updating

- Installed and portable copies of 1.5.0 are offered this release by the updater.
- Copies that are still on a 1.5.0 preview report version 1.5.0 and see this release as an update.

## Validation

- 394 Rust tests, 125 frontend tests and the packaging checks passed locally.
- With a throwaway Claude config folder holding an expired login and a copy of `~/.claude.json`, run without Claude Code's session environment: `claude auth status` left the login untouched, while `claude plugin list` and `claude doctor` attempted the renewal and wrote no other files. The overlay's renewal code was run the same way against the real `claude.exe`.
- Not yet observed end to end with a real login expiring while the overlay runs.
