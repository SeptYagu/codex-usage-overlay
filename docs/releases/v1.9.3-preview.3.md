# Codex Usage Overlay v1.9.3-preview.3

Fix release on top of `v1.9.3-preview.2`. It stops two background paths from opening console windows on Windows and closes three of the known limits carried over from `v1.9.3-preview.1`.

## Fixed

- **Antigravity polling no longer opens a console window.** About every 15 minutes, the `agy` CLI's self-updater relaunched itself outside the overlay's hidden-window setting and opened a visible console (often a Windows Terminal window). Quota polls now run `agy` with `AGY_CLI_DISABLE_AUTO_UPDATE=true`; interactive `agy` sessions keep updating normally. A poll that times out or is cancelled now ends every process it started, including `agy.exe` behind an `agy.cmd` shim. ([#4](https://github.com/SeptYagu/codex-usage-overlay/issues/4))
- **The portable updater no longer opens a console window.** `CodexUsageUpdater.exe` is now a windowless program and is started without a console. ([#4](https://github.com/SeptYagu/codex-usage-overlay/issues/4))
- **A bad value in `providerPreferences` no longer resets all settings.** A wrong-typed value inside `providerPreferences` in a hand-edited `settings.json` now falls back for that field only. Before, the whole file loaded as defaults and was saved over at startup.
- **Migrating a schema v0/v1 `settings.json` keeps an explicit per-provider `protectionEnabled`.** The legacy top-level `autoPauseOnLowQuota` no longer overwrites it, which could silently turn protection off.
- **Stale readings show on time.** The status loop wakes when the next reading is due to go stale, instead of up to 15 seconds later.

## Known limits

- After this preview rewrites `settings.json` to schema v5, `v1.9.2` can still read the file but refuses to save changes to it. To go back to `v1.9.2`, restore or delete `settings.json`.

## 中文说明

基于 `v1.9.3-preview.2` 的修复版：阻止 Windows 上两条后台路径弹出控制台窗口，并解决沿用自 `v1.9.3-preview.1` 的三项已知限制。

### 修复

- **Antigravity 轮询不再弹出控制台窗口。** `agy` CLI 的自动更新程序约每 15 分钟会脱离悬浮窗的隐藏窗口设置重新启动自身，弹出可见的控制台（常见为 Windows Terminal 窗口）。现在额度轮询以 `AGY_CLI_DISABLE_AUTO_UPDATE=true` 运行 `agy`；交互式 `agy` 会话仍正常更新。轮询超时或被取消时，会结束其启动的所有进程，包括经 `agy.cmd` 启动的 `agy.exe`。（[#4](https://github.com/SeptYagu/codex-usage-overlay/issues/4)）
- **便携版更新程序不再弹出控制台窗口。** `CodexUsageUpdater.exe` 改为无窗口程序，并以无控制台方式启动。（[#4](https://github.com/SeptYagu/codex-usage-overlay/issues/4)）
- **`providerPreferences` 中的错误值不再重置全部设置。** 手工编辑的 `settings.json` 中，`providerPreferences` 内类型错误的字段现在只让该字段回退；此前整份文件会按默认值加载，并在启动时被覆盖保存。
- **迁移 schema v0/v1 `settings.json` 时保留显式设置的来源级 `protectionEnabled`。** 旧版顶层 `autoPauseOnLowQuota` 不再覆盖它（此前可能在无提示的情况下关闭保护）。
- **过期读数按时显示。** 状态循环在下一条读数即将过期时唤醒，不再最多延迟 15 秒。

### 已知限制

- 本预览版把 `settings.json` 改写为 schema v5 后，`v1.9.2` 仍可读取该文件，但会拒绝保存修改。如需退回 `v1.9.2`，请还原或删除 `settings.json`。
