# Codex Usage Overlay v1.4.0

This release delivers major upgrades to low-quota protection visibility, responsiveness, safe assisted resumption, and in-thread message routing.

## Highlights

- **Smart Pause Protection Status & Diagnostics**:
  - Settings, the system tray menu and tooltip display live protection health, sample age, effective polling cadence, and per-active-period outcomes.
  - Accepted pause requests and confirmed interruptions are tracked separately.
- **Adaptive 15-Second Polling**:
  - When quota drops near either threshold with protection enabled, the overlay automatically accelerates polling to 15 seconds to catch cutoffs quickly.
  - Hysteresis returns polling to the user-configured interval after two consecutive recovered readings.
- **Localized Pause Signal**:
  - The pause request message matches the overlay display language (`"暂停"` for Simplified Chinese, `"暫停"` for Traditional Chinese, `"Pause"` for English/default).
- **Safe Assisted Resume**:
  - The overlay eliminates autonomous unattended continuation risk by using an assisted resumption model.
  - When quota resets and satisfies recovery verification (two samples $\ge 15$s apart, $\ge \text{threshold} + 2\%$, $\le 30$s fresh), the session plan transitions to `Ready`.
  - Settings displays a one-click `[Resume chat]` action button next to the ready session that dispatches a localized continuation signal (`"继续"` / `"繼續"` / `"Continue"`).
  - Manual resume is guarded and rejected with feedback if quota remains below the threshold.
- **In-Thread Routing & Phantom Chat Fix**:
  - Switched the named-pipe `tools/call` caller identity to match the target thread ID.
  - Resolves an issue where external caller IDs caused the ChatGPT desktop client to create empty/unopenable "ghost" chats with a "Sent from ChatGPT in another chat" badge. Messages now post cleanly inside the active conversation.
- **Hardened Cleanup & Node Action Runtime**:
  - Hardened reader initialization and process cleanup with bounded exit timeouts.
  - Replaced shell-based test helpers with native compiled test fixtures to prevent CI timeouts.
  - Upgraded GitHub Actions to `actions/setup-node@v6` eliminating runtime deprecation warnings.

## Protection limits and migration

**Pause requests remain cooperative.** Accepted delivery requests that the model pause; it does not hard-kill worker processes or verify that background command execution has ceased.

The overlay no longer asks Codex to schedule an external "Continue" timer. If you previously used older versions that created model-scheduled resume tasks, review them in Codex if desired.
