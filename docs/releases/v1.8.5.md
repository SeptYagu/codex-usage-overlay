# Codex Usage Overlay 1.8.5

Fix the tray menu opening by itself. After the menu had been opened and closed once, it could pop open again on its own, most noticeably when usage got low and auto-pause updated the protection status line at the top of the menu.

The menu page keeps rendering while it is hidden, and every change to its size asked the app to lay it out again. That layout always showed and focused the window. Now only a tray click opens the menu: later layouts resize an open menu without taking focus again and do nothing while it is closed.

## Validation and limits

Local Windows validation passed: frontend production build and tests, the Rust test suite, bridge tests, packaging regressions and the affine parity fixture, plus the interactive native tray recovery test. A new regression covers opening, resizing, closing, a status change while closed and reopening. The fix was not exercised by hand in an installed copy; official signed NSIS, MSI and portable packages are built by the tagged Release workflow.

## 中文说明

修复托盘菜单自行弹出的问题：菜单打开并关闭过一次后，可能会自己再次弹出，额度偏低、自动暂停更新菜单顶部的保护状态时最明显。

菜单页面在隐藏后仍会继续渲染，每次尺寸变化都会请求重新布局，而布局总会显示并聚焦窗口。现在只有点击托盘图标才会打开菜单；已打开的菜单只调整尺寸、不再重新抢占焦点，关闭状态下则不做任何操作。

本机 Windows 已通过前端生产构建与测试、Rust 测试、桥接测试、打包回归、仿射一致性检查，以及交互式原生托盘恢复测试。新增回归覆盖打开、调整尺寸、关闭、关闭期间状态变化及再次打开。未在安装版中手动验证；正式签名的 NSIS、MSI 与便携包由标签触发的 Release 工作流构建。
