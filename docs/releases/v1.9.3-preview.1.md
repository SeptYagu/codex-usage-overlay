# Codex Usage Overlay v1.9.3-preview.1

Architecture simplification preview built on top of `v1.9.2` (`165` files changed relative to `main`, `-19,802` net lines), preserving all user-facing provider monitoring, protection, carousel, dock, tray, alert, updater, and saved-state migration behavior while removing duplicated and speculative internals.

## Highlights

- **Shared `agent-bridge` workspace crate & module consolidation**:
  - Extracted shared bridge types, atomic file helpers, localization, and CLI execution into `src-tauri/crates/agent-bridge` shared by `claude-usage-bridge.exe` and `antigravity-usage-bridge.exe` (while preserving `v1.9.2` job-object renewal tree cleanup in `claude-usage-bridge`).
  - Consolidated physical monitor geometry into `geometry.rs`, live polling throttling into `live_poll.rs`, and provider bridge connection UI into `BridgeConnectionCard.tsx`.
  - Stopped re-running Antigravity `.cmd` shim repair on periodic `antigravity_connection_status` polling; repair now runs at startup and explicit `antigravity_connect`.
- **Single-stream runtime state & split modules**:
  - Consolidated monitor ownership on `ProviderRegistry` / `AppServices` and unified frontend usage updates onto `monitor_updated` / `get_monitor_snapshots` (`useProviderMonitors`).
  - Split `commands.rs` and `pause_control.rs` into focused submodules (`commands/*`, `pause_control/*`) and replaced the unconditional 1-second status polling loop with event-driven `status_wake` notifications plus a 15-second probe when Codex protection is active.
- **Burn-rate & pause cleanup without breaking saved user state**:
  - Removed unconsumed `personal.rs`, `shadow.rs`, `replay*`, `burn-rate-shadow-evidence.jsonl`, and `pause-resume-state.json` / disabled `autoResumeAfterQuotaReset` controls.
  - Preserved all three 5H burn-rate selectors (`Legacy`, `Weighted`, `Personalized` via `AffineCalibration`), lossless loading of legacy `settings.json` and `burn-rate-state.json` files, both DSH pairing paths (`Auth::Bridge` with bundled companion `0.1.2` and manual WebSocket fallback), and in-memory manual `resume_chat` / `cancel_resume_plans`.
- **Simplified tray & dock boundaries**:
  - Removed single-caller mock-only traits and pass-through action enums across `tray.rs`, `dock.rs`, and `lib.rs` while keeping pure planners and in-place Windows tray recovery tested.

## 中文说明

基于 `v1.9.2` 的架构精简预览版（相对 `main` 共变更 `165` 个文件、净减少 `19,802` 行），在完整保留所有来源监控、保护、轮换、贴边、托盘、告警、自动更新和历史配置迁移的前提下，清理重复模块与未消费内部流水线。

### 主要更新

- **抽取共享 `agent-bridge` 工作区 crate 与模块整合**：
  - 将 Claude / Antigravity 桥接程序的公共类型、原子写入、多语言提示与 CLI 调用整合至 `src-tauri/crates/agent-bridge`（同时保留 `v1.9.2` 中 `claude-usage-bridge` 的 Windows 作业对象进程树回收）。
  - 合并矩形与显示器选择到 `geometry.rs`，合并实时轮询节流到 `live_poll.rs`，并将两套桥接状态卡片整合为 `BridgeConnectionCard.tsx`。
  - 不再在周期性 `antigravity_connection_status` 轮询中重复执行 `.cmd` 垫片修复，仅在启动和显式连接时修复。
- **统一监控状态流与拆分大文件**：
  - 统一 `ProviderRegistry` 与 `AppServices` 所有权，并将前端读数入口收拢为单一 `monitor_updated` / `get_monitor_snapshots` 数据流（`useProviderMonitors`）。
  - 拆分原 `commands.rs` 与 `pause_control.rs` 为职责单一的子模块，将后端 1 秒无条件状态轮询改为按 `status_wake` 唤醒并在开启 Codex 保护时按 15 秒兜底探测。
- **保留历史配置与核心预测能力的精简**：
  - 移除未消费的标量预测/遥测回放模块（`personal.rs`、`shadow.rs`、`replay*`、`burn-rate-shadow-evidence.jsonl`）以及永久禁用的 `autoResumeAfterQuotaReset` 界面与 `pause-resume-state.json` 状态机。
  - 完整保留 `Legacy`、`Weighted`、`Personalized`（`AffineCalibration`）三档 5H 消耗速率算法、旧版 `settings.json` 与 `burn-rate-state.json` 无损迁移、DSH 双配对通路（自动伴侣 `0.1.2` 与手动 WebSocket 回退）及会话内手动恢复对话功能。
- **精简托盘与贴边抽象层**：
  - 去掉仅用于 mock 转发的单方法 trait 与中间动作枚举，保留纯规划函数及可测的 Windows 原位托盘恢复逻辑。
