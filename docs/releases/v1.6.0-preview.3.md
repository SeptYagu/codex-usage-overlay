# Codex Usage Overlay v1.6.0-preview.3

## Monitor multiple providers and switch with the logo

- Available enabled **local Codex, Claude and DSH providers keep monitoring in the background**, with independent polling, cached readings, burn-rate histories, retry state and reset notifications. One slow or failed read does not block the others.
- **Click the provider logo** to cycle Local Codex → Claude → DSH, skipping providers without an available reading or with monitoring disabled. Switching uses cached data immediately and does not reconnect a provider, reset history or change protection. Enter/Space also activate the logo; dragging the rest of the overlay and right-click menus are preserved.
- Settings separates **Displayed provider** from **Provider settings**. Select a provider to configure its monitoring and protection without changing the displayed source. English, Simplified Chinese and Traditional Chinese are supported throughout.
- **Protection is independent for each provider**, including background providers. Migration preserves the previously selected provider's protection setting; other providers start with protection off. Turning off monitoring also turns off that provider's protection. Existing histories, Claude live-reading consent and explicit DSH bindings are retained.

## Visibility and tray fixes

- **Show/hide is remembered across restarts.** A previously hidden overlay starts hidden without flashing; background monitoring and tray controls remain available. A missing tray falls back to a visible overlay for recovery.
- The tray icon now renders the **displayed provider's quota** immediately on switching. Other providers cannot overwrite it. A temporary read failure retains that provider's last ring values while the tooltip reports the failure.
- Provider-labelled reset notifications remain deduplicated by source/quota/cycle. DSH account switches retain the process's pause-attempt ledger; changing the displayed logo does not re-arm a pause request.

## Setup and limits

Monitoring uses existing configured connections. Claude live reading stays opt-in and is limited to once a minute. Bridge-only Claude readings update when Claude Code emits them. DSH still requires explicit instance pairing, account selection and target-session selection; this release does not automatically connect or monitor every DSH account.

Pause remains cooperative for Codex/DSH; delivery does not prove interruption. Automatic resume remains unavailable. The companion is unchanged: `dsh-codex-usage-overlay-bridge-0.1.0.tgz`. See the [DSH guide](https://github.com/SeptYagu/codex-usage-overlay/blob/v1.6.0-preview.3/docs/dsh-subscription.md).

Local validation: **161 frontend tests**, TypeScript/Vite production build, **422 main-library + 10 helper Rust tests** (7 existing ignored), **15 companion tests**, companion packaging and **7 packaging regressions**. Edge checks cover provider switching by mouse and keyboard, independent Settings selection, both themes/layouts, all three languages and scaled quota bars.

An isolated Windows debug session read real Codex and Claude quotas and updated their separate histories while Codex was displayed. After restarting with saved hidden state, no QA overlay window appeared and both providers continued reading successfully. Native WebView2 clicks, mixed-monitor docking, installed-package behavior and real protected-session dispatch remain unverified: Computer Use denied access to the QA window. Browser interaction and backend regressions cover the corresponding logic. The release workflow repeats tests and creates signed Windows updater packages.

Enable **Include preview releases** to receive this version through the updater, or install a package from this release. The stable update channel is unchanged.

## 多来源后台监控与图标切换

- 已连接且启用的本机 Codex、Claude 和 DSH 会持续在后台监控，各自保存读数、消耗速率历史、重试和重置状态。单个来源读取缓慢或失败不会阻塞其他来源。
- 点击浮窗来源图标，按 Codex → Claude → DSH 轮换显示，跳过尚无可用读数或已关闭监控的来源。使用缓存立即显示，支持 Enter/空格键；切换显示不会重连、清空历史或改变保护开关。
- 设置将「浮窗显示来源」和「来源设置」分开；可以配置后台来源而不改变当前显示。界面完整支持英文、简体中文和繁体中文。
- 各来源的保护独立生效。升级仅保留原来所选来源的保护开启状态，其他来源默认关闭保护；关闭某来源的监控也会关闭其保护。Claude 实时读取授权和 DSH 的显式配对规则保持不变。
- 显示/隐藏状态会跨重启保存：上次隐藏时，下次启动直接隐藏，监控和托盘仍然工作。修复托盘图标未正确绘制当前来源额度的问题；后台来源不会覆盖当前图标，临时读取失败时保留上次额度环并在提示中报告错误。
- 已执行前端、Rust、companion、包装和 Edge 交互检查；隔离的 Windows 会话验证了 Codex/Claude 后台读数和隐藏启动。Computer Use 未获准访问 QA 窗口，原生点击、多屏贴边、安装包实机及真实会话保护仍待验收，因此继续发布预览版。
