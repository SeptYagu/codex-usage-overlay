# Codex Usage Overlay v1.11.0-preview.1

Preview of a reorganized Settings window. Built on `v1.10.1`.

## Changed

- **Sidebar navigation.** The Settings window now has a sidebar instead of a row of tabs. App-wide pages come first, then a **Providers** group with one page per provider. A dot marks the provider the overlay is showing. The arrow keys, Home and End move between pages, and each page opens at its top.
- **Headed sections.** Every page groups its settings under section headings:
  - **General**: Language and startup (language, start on boot), Updates (automatic checks, automatic installation, preview releases).
  - **Overlay**: Appearance (layout, size, transparency), Show on overlay (5-hour quota, provider logo, credit balance, burn rate), Behavior (auto hide at screen edge, percentage grid, mouse click-through).
  - **Quota rotation**: rotation and its interval, plus **Included providers**, which lists all four providers together. Each provider page used to carry its own "Include in quota rotation" checkbox.
  - **Usage history**: Recording (record, open, clear), and Timeline, which chooses whether the timeline shows remaining or used quota. This is the same setting as the switch in the History window.
  - **Each provider**: Monitoring (monitor, connection, refresh interval), Protection (pause or block thresholds, protection status, and Codex's pause messages), Display (5-hour burn-rate estimate), Notifications (reset alerts and sounds).
- Checkbox and dropdown rows share one style.

No setting changes its meaning, default or stored value, so nothing needs migrating.

## Verification and limits

- The full frontend, Rust, DSH companion, packaging and Claude process-tree checks pass locally. New tests cover the sidebar order, arrow-key navigation, section headings, the marker for the displayed provider, the rotation list and the timeline choice.
- Every page was checked in a browser preview, in light and dark themes and at the 760-pixel minimum window width. The new layout has not been checked in an installed copy.
- The ARM64 packages from `v1.10.1` have still not been installed on an ARM64 PC.

## 中文说明

本预览版重新整理了设置窗口，基于 `v1.10.1`。

- **侧边栏导航。** 设置窗口改用侧边栏代替顶部标签：先是应用级页面，再是“来源”分组，每个来源一页。浮窗正在显示的来源旁有圆点标记。可用方向键、Home 和 End 切换页面，每页从顶部打开。
- **分节标题。** 每页的设置都按标题分组：
  - **通用**：语言与启动（语言、开机自启）、更新（自动检查、自动安装、预览版）。
  - **浮窗**：外观（布局、大小、透明度）、浮窗显示内容（5 小时额度、来源图标、余额、消耗速率）、行为（贴边自动隐藏、百分比刻度、鼠标穿透）。
  - **额度轮播**：轮播开关与间隔，以及集中列出四个来源的“参与轮播的来源”（此前每个来源页各有一个“参与额度轮播”复选框）。
  - **用量历史**：记录（记录、打开、清除），以及时间折线显示剩余或已用额度（与历史窗口中的切换为同一设置）。
  - **各来源**：监控（监控、连接、刷新间隔）、保护（暂停或拦截阈值、保护状态及 Codex 暂停消息）、显示（5 小时消耗速率估算）、通知（重置提醒与提示音）。
- 复选框和下拉框行使用统一样式。

所有设置的含义、默认值和存储值均未改变，无需迁移。本机前端、Rust、DSH 配套组件、打包和 Claude 进程树检查均通过；各页面已在浏览器预览中以浅色、深色主题和 760 像素最小窗口宽度检查，尚未在安装版中实测。
