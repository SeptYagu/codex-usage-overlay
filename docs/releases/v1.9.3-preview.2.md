# Codex Usage Overlay v1.9.3-preview.2

Fix release on top of `v1.9.3-preview.1`. It corrects one regression from the architecture simplification and restores test coverage in the release gate.

## Fixed

- **Source-specific settings no longer reset unrelated providers.** In `v1.9.3-preview.1`, turning Claude or Antigravity live reading on or off, or a change to the DSH session binding (including a DSH auto-reconnect), was treated as a change for all four providers. Each of them dropped its in-flight read, cancelled pending pause delivery and re-polled at once. Only the provider that owns the setting reacts now.
- **The release gate runs the bridge tests again.** The `CI` and `Release overlay` workflows now run `cargo test --workspace`, so the 21 guard and statusline tests in the `agent-bridge` crate are part of every run.

## Known limits carried over from v1.9.3-preview.1

- After this preview rewrites `settings.json` to schema v5, `v1.9.2` can still read the file but refuses to save changes to it. To go back to `v1.9.2`, restore or delete `settings.json`.
- A wrong-typed value inside `providerPreferences` in a hand-edited `settings.json` makes the whole file load as defaults.
- A partially migrated schema v0/v1 `settings.json` can lose an explicit per-provider `protectionEnabled`.
- Time-driven status changes, such as a reading turning stale, can appear up to 15 seconds late.

## 中文说明

基于 `v1.9.3-preview.1` 的修复版，修正架构精简引入的一处回归，并恢复发布门槛中的测试覆盖。

### 修复

- **来源专属设置不再重置其他来源。** 在 `v1.9.3-preview.1` 中，开关 Claude 或 Antigravity 实时读取，或 DSH 会话绑定发生变化（包括 DSH 自动重连），会被当作全部四个来源的变更：每个来源都会丢弃进行中的读取、取消待发送的暂停请求并立即重新轮询。现在只有拥有该设置的来源会响应。
- **发布门槛重新运行桥接测试。** `CI` 与 `Release overlay` 工作流改为运行 `cargo test --workspace`，`agent-bridge` crate 中的 21 项守卫与状态栏测试重新纳入每次运行。

### 沿用自 v1.9.3-preview.1 的已知限制

- 本预览版把 `settings.json` 改写为 schema v5 后，`v1.9.2` 仍可读取该文件，但会拒绝保存修改。如需退回 `v1.9.2`，请还原或删除 `settings.json`。
- 手工编辑的 `settings.json` 中，`providerPreferences` 内任一字段类型错误会导致整份设置按默认值加载。
- 部分迁移的 schema v0/v1 `settings.json` 可能丢失显式设置的来源级 `protectionEnabled`。
- 由时间推移触发的状态变化（例如读数变为过期）最多可能延迟 15 秒显示。

### 验证范围与已知边界

- 打标签前已在标签对应源码上通过本地校验：`Test-TauriRelease.ps1`、`npm run build`、`npm test`（14 文件 / 190 用例）、`integrations/dsh-bridge/test/*.test.js`（16/16）、`Package-DshCompanion.ps1`（`0.1.2`）、`cargo test --workspace --locked`（`agent_bridge` 21 通过、`codex_usage_overlay_lib` 387 通过 / 5 忽略）及 `Test-ClaudeRenewProcessTree.ps1`。
- 修复提交在其拉取请求中的 GitHub Windows `CI` 已通过。标签在上述本地校验通过后推送，未等待版本号提交的 `CI` 运行；`Release overlay` 工作流在打包前会再次运行测试。
- 正式签名的 NSIS/MSI 安装包、便携包、`.sig` 与 `latest.json` 由 GitHub Actions `Release overlay` 工作流构建并签名；在设置中开启 **Include preview releases**（包含预览版本）即可通过内置更新器接收此预览版。
- 本预览版尚未进行交互式桌面 GUI 验收、5 项 `#[ignore]` 用例，以及签名安装包和内置预览更新通道的实机烟测。
