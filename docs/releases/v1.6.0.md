# Codex Usage Overlay v1.6.0

## Multiple providers, one overlay

- Local Codex, Claude and DSH monitor independently in the background, with separate cached readings, histories, retry state, reset notifications and protection preferences. A slow or failed provider does not block the others.
- Click the overlay's provider logo to cycle through available enabled providers. Enter/Space also work. Switching immediately displays cached data and keeps background monitoring and protection running.
- Settings separates **Displayed provider** from **Provider settings**. Turning off a provider's monitoring also disables its protection. On upgrade, only the previously selected provider inherits enabled protection; other providers start with protection off. Existing histories and Claude live-reading consent are preserved.

## Automatic DSH connection

- Enabled DSH monitoring discovers a supported running Desktop and, when needed, configures the bundled companion through Desktop's official CLI. Discovery, authentication and active-account reading continue even while Codex or Claude is displayed.
- Automatic setup supports Windows and the default Desktop home. It uses the embedded companion **0.1.1**, offline installation and disabled package scripts. It does not restart DSH, override a disabled companion, choose arbitrarily among uncertain instances, or use local Codex readings as a fallback.
- Reconnecting to the same profile restores quota reading. Pause sessions always require explicit selection for the current connection; old targets are cleared after reconnect/account changes. Disconnect stays suspended until Retry. A compatibility connection-link form remains available.
- Connection changes cancel old queued reads and unsent pause requests before replacing the transport. Target selection checks the current connection revision, including when DSH is a background provider.

## Visibility, tray and settings

- Show/hide is remembered across launches. A previously hidden overlay starts hidden while monitoring continues; an unavailable tray reveals it for recovery.
- Tray quota rings follow the displayed provider immediately. Background providers cannot overwrite them. Temporary read errors preserve cached rings and report the failure in the tooltip.
- Settings descriptions are clearer in English, Simplified Chinese and Traditional Chinese. **Show 10% grid on edge bars** appears only with **Auto hide at screen edge** enabled. Empty-track colors and scaling/clipping of collapsed quota bars are fixed.

## Validation and limits

Local checks passed: **186 frontend tests**, TypeScript/Vite production build, **446 main-library + 10 helper Rust tests** (8 ignored), **16 companion tests**, companion package verification and **7 packaging regressions**. The 18 DSH transport tests include automatic discovery, background binding/disconnect, account/profile changes, stale target rejection and cancellation while a handshake is pending. The release workflow repeats tests and builds signed Windows updater packages.

Earlier isolated Windows checks verified real Codex/Claude background readings and hidden startup. This machine has no identifiable running DSH Desktop, so the opt-in real Desktop CLI test stopped at discovery; no real DSH profile was modified. DSH Host hot reload, live subscription reading and real pause delivery remain unverified here. Native WebView2 clicks, mixed-monitor docking and installed-package smoke checks also remain unverified. These limits are not counted as passing tests.

Codex/DSH pause requests are cooperative; accepted delivery does not prove interruption. Automatic resume remains unavailable. Claude live reading remains opt-in. See the [DSH setup guide](https://github.com/SeptYagu/codex-usage-overlay/blob/v1.6.0/docs/dsh-subscription.md).

This is a **stable** release. Both stable and preview installations can update to v1.6.0; including preview releases is not required.

## 中文说明

- 本机 Codex、Claude、DSH 独立后台监控，各自保存读数、历史、重试、重置通知和保护设置。点击浮窗来源图标或按 Enter/空格键切换，立即显示缓存；后台监控不受影响。
- 「浮窗显示来源」和「来源设置」分开。关闭某来源监控也会关闭其保护；升级只将原有保护开启状态迁移至原来所选来源，其他来源默认关闭保护。
- DSH 监控开启时会发现运行中的 Desktop，必要时通过官方 CLI 自动配置随包 companion **0.1.1**，认证后读取当前活动订阅账户；浮窗显示其他来源时也继续工作。自动配置仅支持 Windows 默认 Desktop home，不会擅自重启 DSH 或重新启用已禁用的插件。
- 重连或账户变化后清空旧暂停目标，必须明确重新选择；目标绑定核对当前连接版本。主动断开后保持暂停自动连接，点击重试才能恢复。旧排队读取和未发出的暂停请求会在连接替换前撤销，不混用本机 Codex 额度。
- 显示/隐藏状态跨重启保存；托盘额度环跟随当前显示来源，临时读取失败时保留缓存并提示错误。优化中、英、繁体设置说明；10% 贴边刻度选项仅在自动贴边隐藏开启时显示，并修复缩放和空轨道颜色。
- 前端、Rust、companion 和包装回归均通过。本机没有运行中的 DSH Desktop，真实 CLI 安装测试在发现阶段停止，未修改真实 profile；真实 Host 热加载、订阅读数、暂停及原生安装包等验收边界见上文，未计作通过。暂停仅为协作式请求，送达不代表已经停止，不支持自动恢复。
- 本版为 **v1.6.0 正式版**，稳定版和预览版均可更新，无需开启接收预览版。
