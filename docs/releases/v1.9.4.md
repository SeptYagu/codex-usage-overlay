# Codex Usage Overlay v1.9.4

Patch release after `v1.9.3` that adds Russian as an interface language.

## Added

- **Russian interface.** Choose Russian under Common settings → Language, or let the overlay pick it automatically on a Russian Windows locale. The overlay, settings, tray menu and tooltips, notifications, and the default pause and resume messages sent to Codex are all translated. The compact overlay uses short Russian labels (`5 ч`, `Нед.`, `Арг.`, `Кр.`). Contributed by @TrofimenkovD. ([#6](https://github.com/SeptYagu/codex-usage-overlay/pull/6))

## Changed

- The compact overlay's short labels (`5H`, `WK`, `AR`, `CR`) are now part of each language's translations instead of being hardcoded in the overlay. English and Chinese show the same labels as before. A new test checks that every language defines exactly the same translation keys as English.

## Upgrade note

- No settings migration from `v1.9.3`. If you upgrade straight from `v1.9.2`, the `v1.9.3` note still applies: `settings.json` is rewritten to schema v5, which `v1.9.2` can read but will not save.

- `codex-usage-overlay_1.9.4_x64_en-US.msi` (MSI installer, plus `.sig`)

## 中文说明

`v1.9.3` 之后的补丁版本，新增俄语界面。

### 新增

- **俄语界面。** 可在“通用设置 → 语言”中选择俄语；Windows 系统语言为俄语时也会自动选用。悬浮窗、设置、托盘菜单与提示、通知，以及发送给 Codex 的默认暂停与继续消息均已翻译。紧凑布局使用俄语短标签（`5 ч`、`Нед.`、`Арг.`、`Кр.`）。由 @TrofimenkovD 贡献。（[#6](https://github.com/SeptYagu/codex-usage-overlay/pull/6)）

### 变更

- 紧凑布局的短标签（`5H`、`WK`、`AR`、`CR`）改为写入各语言的翻译，不再硬编码在悬浮窗组件中；英文与中文显示不变。新增测试，检查每种语言的翻译键与英文完全一致。

### 升级提示

- 从 `v1.9.3` 升级无需迁移设置。若从 `v1.9.2` 直接升级，`v1.9.3` 的提示仍然适用：`settings.json` 会改写为 schema v5，`v1.9.2` 可以读取但不会保存。
