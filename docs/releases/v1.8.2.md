# Codex Usage Overlay v1.8.2

**Stable bugfix release / 正式修复版** — 2026-11-08

## Fix

DSH quota reading no longer reports an automatic connection failure when DSH's optional `session/list` API fails. The settings page reports that pause target selection is unavailable while the session service is down. The connection keeps reading the active subscription account; pause targets remain opt-in and cannot be selected without a working session list.

## Validation and limits

The source commit must pass Windows GitHub CI before tagging. The tagged Release workflow builds and signs the NSIS, MSI and portable packages; its result and assets are checked separately. On the affected machine, the DSH bridge's subscription status and usage requests succeeded while `session/list` returned an upstream error. A new installed-package UI check remains unperformed.
