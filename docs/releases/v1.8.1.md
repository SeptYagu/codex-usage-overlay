# Codex Usage Overlay v1.8.1

**Stable bugfix release / 正式修复版** — 2026-11-08

## Changes

- The settings window now uses scrollable tabs, so provider settings fit in narrower windows and future profile pages have a place to live.
- DSH automatic setup can fetch a missing profile dependency from its GitHub source. The previous offline install failed when that dependency was not already in the local pnpm cache.

## Validation and limits

The source commit passed the Windows GitHub CI frontend build, frontend and DSH companion tests, and Rust tests. The tagged Release workflow builds the Windows NSIS, MSI and portable ZIP packages; its result and assets must be checked separately. Native installed-window layout and a clean-machine DSH setup have not been verified for this patch.
