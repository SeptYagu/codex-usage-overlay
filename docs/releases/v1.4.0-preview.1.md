# Codex Usage Overlay v1.4.0-preview.1

This preview improves low-quota protection visibility, response time and stale-request handling. App/package version: 1.4.0.

The initial preview's CI timed out starting its PowerShell test helpers, and its release run was cancelled. This correction uses the compiled Rust test executable as the owned-process fixture. All four cleanup regressions remain active with their original deadlines. CI and release also upgrade to `actions/setup-node@v6`, removing its deprecated Node 20 runtime while keeping project builds on Node 22.

- Settings, the tray menu and tooltip show protection health. Details report each observed active period and distinguish accepted pause requests from verified interruption.
- With protection enabled, polling accelerates to 15 seconds near either quota threshold, returns to the normal interval after two recovered readings, and backs off after failures.
- New quota data, failed reads, account changes and settings changes invalidate unsent pause work. Bounded delivery batches rotate between chats so a slow target cannot permanently starve later targets.
- Reader initialization and owned-process cleanup are hardened, and quota-window duration and payload validation reject malformed or unrelated usage data.
- A separate automatic-resume preference defaults to off. Durable eligibility, expiry, restart review and unknown-submission handling are present for a future verified control adapter.

## Protection limits and migration

**Pause requests remain cooperative. Accepted delivery does not prove that inference, queued work or background commands stopped.** The current desktop connection has no verified exact-turn interruption/completion or later-user-activity observation, so direct interruption and automatic continuation remain disabled. Cooperative acceptance cannot create an executable resume plan.

Requests contain only “暂停” (pause). The overlay no longer asks Codex to create an external “Continue” timer. **Older Codex-created continuation tasks may still run; disabling overlay protection does not cancel those external tasks.** Review them in Codex if you previously used that behavior.

## Validation

- 107 frontend tests and 330 regular Rust tests passed locally. The four existing ignored estimator replays remain; one additional ignored entry is the subprocess fixture, executed explicitly by the four active lifecycle regressions.
- Production frontend build, locked all-target Rust check, six packaging fixtures and 526 Edge layout cases passed during release preparation.
- Three isolated read-only usage-reader measurements took 396–427 ms; all owned processes exited after cleanup. This is a short sample, not a long-running resource soak.

Native installed-package, WebView2/tray, mixed-monitor and real interruption/automatic-resumption smoke tests have not been performed for this preview. The release workflow builds and signs the installers and portable ZIP from the tagged source; its result must be checked separately from local tests.
