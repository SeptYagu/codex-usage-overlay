# Codex Usage Overlay 1.9.2

Fix accumulated Claude Code processes during automatic renewal of an expired terminal login.

When live Claude reading detects an expired CLI login, the overlay runs `claude plugin list` and, if needed, `claude doctor`. These commands now run through the bundled bridge inside a Windows job. The job closes when the bridge finishes or times out, so any Claude Code processes started by a batch shim are also stopped. The 10-minute renewal limit and 30-second per-command deadline remain in place.

The screenshot that prompted this fix showed seven Claude Code processes and seven console hosts under the overlay. It did not include command lines or a process tree, so the exact origin of those particular processes is unconfirmed. The fixed path is the overlay's only direct Claude CLI launch path.

## Validation and limits

The source checks and Windows CI result for this commit are the release gate. A local Rust build is unavailable because this machine has no MSVC linker. The user's affected machine and its installed package have not been retested.
