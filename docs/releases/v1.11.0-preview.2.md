# Codex Usage Overlay v1.11.0-preview.2

Preview of the unified usage-history controls and configurable local retention. Built on `v1.11.0-preview.1`.

## Changed

- **Timeline display.** The History window now has a labeled **Remaining / Used** dropdown. Settings → Usage history puts the same choice beside **Open usage history** and explains where the timeline appears. Both use the same saved setting; daily consumption and quota-window calculations are unchanged.
- **History retention.** Choose **Three months**, **Six months**, **One year** or **Keep all** in Settings → Usage history. **Keep all** is the default, including when upgrading an existing configuration without this setting. Stopping recording stops new readings; the selected retention still applies to files already saved. Choosing a shorter period shows an estimate of the readings and disk space to remove and requires confirmation. The page also shows disk usage and the earliest and latest saved readings. A failed cleanup is reported and retried on the next start.
- **Viewing range.** The History window still offers 24 hours, 7 days, 30 days and 90 days. Older saved readings remain on disk according to the selected retention period, but the window does not display them yet. No extra quota requests are made.

Retention uses UTC calendar months. A shorter period removes expired files and expired readings from the boundary month. Deleted readings cannot be recovered by selecting a longer period. History already deleted by older releases cannot be restored by this update.

## Verification and limits

- Frontend tests and build pass locally. The Windows CI run is the native Rust and packaging regression gate for the tagged source.
- The Settings and History layout has not been checked in an installed copy of this preview; the ARM64 packages have not been installed on an ARM64 PC.
- Importing older prediction-state data remains a separate proposal; this preview does not import inferred readings into the formal history.

## 中文说明

本预览版统一了用量历史的显示方式，并加入本机历史保留期限设置，基于 `v1.11.0-preview.1`。

- **折线显示。** 独立的“用量历史”窗口以带标签的下拉框选择“剩余额度”或“已用额度”。设置 → 用量历史将同一选项放在“打开用量历史”旁边，并说明折线的位置。两处共用同一个已保存设置；每日消耗和额度窗口统计不变。
- **历史保留。** 可选“三个月”“六个月”“一年”“全部保留”。新旧配置均默认“全部保留”。停止记录只停止新增读数，已有文件仍按所选期限处理。缩短期限前会预估将删除的读数和空间并要求确认；页面显示磁盘占用、最早和最新读数。清理失败会提示，并在下次启动重试。
- **查看范围。** 历史窗口仍提供 24 小时、7 天、30 天和 90 天。超出 90 天但仍在保留期限内的读数会留在磁盘，当前窗口暂不展示；不会增加额度请求。

期限按 UTC 日历月计算，缩短期限会删除过期整月文件及边界月内的过期读数。已删除的读数无法通过改回较长期限恢复；旧版本此前删除的历史也无法恢复。本预览版不把旧预测状态中的推算点导入正式历史。

前端测试与构建已在本地通过；标签源码的 Windows CI 是 Rust 和打包回归检查关卡。尚未在本预览版安装包中检查设置和历史布局，ARM64 安装包也尚未在 ARM64 电脑上实装。
