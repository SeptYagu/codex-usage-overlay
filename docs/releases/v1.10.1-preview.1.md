# Codex Usage Overlay v1.10.1-preview.1

Preview of Windows ARM64 packages, plus one usage history fix.

## Added

- **Windows ARM64 packages.** This release ships the NSIS installer, MSI and portable ZIP built natively for ARM64 (`arm64` in the file name) next to the x64 ones. Each architecture is built and tested on its own GitHub runner, and both are published in one `latest.json`.
- **The updater stays on your architecture.** An installed or portable copy updates only from packages of its own architecture. An x64 copy running under emulation on an ARM64 PC keeps updating to x64. To switch to the native build, install the ARM64 package. Settings and history are kept, because both builds use the same `%LOCALAPPDATA%\CodexUsageOverlay` folder.

## Fixed

- **An Antigravity 5-hour reset is drawn once.** After a reset, agy can report an unused 0% window running to the next five-hour mark and then no window at all. The History window took that drop as a second reset (for example at 01:46 after a 01:12 reset) and listed an empty window. Now any window at 0% counts as not in use, for every provider, and its reported reset time is ignored. Existing history files are read with the same rule.

## Verification and limits

- The frontend, Rust and DSH companion tests and the Claude process-tree check pass on GitHub's ARM64 runner (`windows-11-arm`) and locally on x64. This includes building `ring` natively for ARM64.
- **This is the first release that builds the ARM64 NSIS installer and MSI.** The ARM64 packages have not been installed or run on an ARM64 PC. Please report any install or startup problems.
- The Antigravity fix was checked against real agy history recorded on this machine.

## Included assets

- `codex-usage-overlay_1.10.1-preview.1_x64-setup.exe` and `codex-usage-overlay_1.10.1-preview.1_arm64-setup.exe` (NSIS installers, plus `.sig`)
- `codex-usage-overlay_1.10.1-preview.1_x64_en-US.msi` and `codex-usage-overlay_1.10.1-preview.1_arm64_en-US.msi` (MSI installers, plus `.sig`)
- `CodexUsageOverlay-v1.10.1-preview.1-Windows-x64.zip` and `CodexUsageOverlay-v1.10.1-preview.1-Windows-arm64.zip` (portable archives, plus `.sig`)
- `dsh-codex-usage-overlay-bridge-0.1.2.tgz` (DSH companion package, unchanged)
- `latest.json` and `SHA256SUMS.txt`

Enable **Include preview releases** in Settings to receive this prerelease.

## 中文说明

本预览版新增 Windows ARM64 安装包，并修复一处用量历史问题。

- **Windows ARM64 安装包。** 除 x64 外，现同时提供原生 ARM64 版本的 NSIS 安装包、MSI 和便携 ZIP（文件名含 `arm64`）。两种架构分别在各自的 GitHub 运行器上构建和测试，并合并到同一个 `latest.json`。
- **更新不跨架构。** 应用只从与自身架构相同的安装包更新。在 ARM64 电脑上以模拟方式运行的 x64 版本会继续更新到 x64；如需改用原生版本，请安装 ARM64 安装包。两种版本使用同一个 `%LOCALAPPDATA%\CodexUsageOverlay` 目录，设置和历史都会保留。
- **Antigravity 的 5 小时重置只画一次。** agy 在重置后可能先返回一个到下一个五小时整点、用量为 0% 的未使用窗口，之后不再返回窗口。此前历史会把这次变化当作第二次重置（例如 01:12 重置后又在 01:46 标一次），并列出一个空窗口。现在所有来源中用量为 0% 的窗口都视为未使用，忽略其重置时间；已有历史文件按同样规则读取。

前端、Rust、DSH 配套组件测试和 Claude 进程树检查已在 GitHub 的 ARM64 运行器和本机 x64 上通过。这是首次构建 ARM64 的 NSIS 和 MSI 安装包，尚未在 ARM64 电脑上安装或运行，如遇安装或启动问题请反馈。
