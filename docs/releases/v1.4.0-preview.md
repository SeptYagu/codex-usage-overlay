# Codex Usage Overlay v1.4.0-preview

This preview improves low-quota protection visibility, response time and stale-request handling. App/package version: 1.4.0.

- Settings, the tray menu and tooltip now show protection health. Details report each observed active period and distinguish accepted pause requests from verified interruption.
- With protection enabled, polling accelerates to 15 seconds near either quota threshold, returns to the normal interval after two recovered readings, and backs off after failures.
- New quota data, failed reads, account changes and settings changes invalidate unsent pause work. Bounded delivery batches rotate between chats so a slow target cannot permanently starve later targets.
- Reader initialization and owned-process cleanup are hardened, and quota-window duration and payload validation reject malformed or unrelated usage data.
- A separate automatic-resume preference defaults to off. Durable eligibility, expiry, restart review and unknown-submission handling are present for a future verified control adapter.

## Protection limits and migration

**Pause requests remain cooperative. Accepted delivery does not prove that inference, queued work or background commands stopped.** The current desktop connection has no verified exact-turn interruption/completion or later-user-activity observation, so direct interruption and automatic continuation remain disabled. Cooperative acceptance cannot create an executable resume plan.

Requests now contain only “暂停” (pause). The overlay no longer asks Codex to create an external “Continue” timer. **Older Codex-created continuation tasks may still run; disabling overlay protection does not cancel those external tasks.** Review them in Codex if you previously used that behavior.

## Validation

- 107 frontend tests and 330 Rust tests passed; four pre-existing ignored estimator replays are unchanged.
- Production frontend build and locked all-target Rust check passed.
- All six packaging regression fixtures and 526 Edge layout cases passed, covering three languages and collapsed/expanded protection details.
- Three isolated read-only usage-reader measurements took 396–427 ms; all owned processes exited after cleanup. This is a short sample, not a long-running resource soak.

Native installed-package, WebView2/tray, mixed-monitor and real interruption/automatic-resumption smoke tests have not been performed for this preview. The release workflow builds and signs the installers and portable ZIP from the tagged source; its result must be checked separately from these local tests.
