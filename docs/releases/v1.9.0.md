# Codex Usage Overlay v1.9.0

This release adds first-class **Antigravity** (`antigravity`) usage monitoring alongside Codex, Claude, and DSH, and makes automatic update checks run immediately at launch with backend-delivered update notifications.

## Highlights

- **Antigravity provider integration**:
  - Independent background monitor, overlay display switching (`Codex -> Claude -> DSH -> Antigravity`), tray menu integration, dedicated Settings tab, and localization in `en-US`, `zh-CN`, and `zh-Hant`.
  - Dual-source quota capture combining live `agy /usage` polling (`antigravity_live_polling`, enabled by default) with the bundled `antigravity-usage-bridge.exe` (`statusline` JSON capture written to `%LOCALAPPDATA%\CodexUsageOverlay\antigravity-rate-limits.json` while chaining and backing up existing `~/.gemini/antigravity-cli/settings.json`).
  - `PreInvocation`-only low-quota guard hook integration via `~/.gemini/config/hooks.json`, including Windows `.cmd` shim and short-path-safe quoting so commands invoke reliably when paths contain spaces.
  - Multi-pool selector (`auto`, `gemini`, `argon`, `3p`) with pool-isolated burn-rate history (`antigravity-<pool>`) and optional AI Credits extraction.
  - Colourful four-pointed Gemini star logo for Antigravity in the overlay and settings tabs.
- **Launch-time update checks & reliable update notifications**:
  - When automatic update checks are enabled, the updater checks immediately at launch (instead of waiting 15 seconds) before returning to the 12-hour interval, retrying failed checks after 30 s, 2 min, and 10 min.
  - Emits update notifications directly from the Rust backend whenever an automatic check finds an update (and notifies when an auto-installed update is downloaded and ready to install on quit, once per state per version) so launch-time findings are not lost before the overlay frontend attaches.

## 中文说明

本版本新增一等支持的 **Antigravity**（`antigravity`）用量监控来源，并将自动更新检查提前到启动时执行、改为后端直接发送更新系统通知。

### 主要更新

- **Antigravity 来源支持**：
  - 提供独立后台监控、浮窗来源轮换（`Codex → Claude → DSH → Antigravity`）、托盘菜单集成、独立设置选项卡，以及 `en-US`、`zh-CN`、`zh-Hant` 多语言文案。
  - 结合实时 `agy /usage` 轮询（`antigravity_live_polling` 默认开启）与内置助手 `antigravity-usage-bridge.exe`（通过 `statusline` 采集配额写入 `%LOCALAPPDATA%\CodexUsageOverlay\antigravity-rate-limits.json`，并自动串联与备份已有 `~/.gemini/antigravity-cli/settings.json`）。
  - 支持在 `~/.gemini/config/hooks.json` 安装仅限 `PreInvocation` 的低配额保护钩子，并修复 Windows `.cmd` 包装脚本与带空格路径下的命令引用。
  - 支持多配额池切换（`auto`、`gemini`、`argon`、`3p`）、按 `antigravity-<pool>` 隔离的消耗速率历史，以及可选 AI Credits 展示。
  - 浮窗与设置页面使用彩色四角星 Gemini 来源图标。
- **启动即检查更新与稳定通知**：
  - 开启自动检查更新后，应用启动时立即检查（不再延迟 15 秒），检查失败按 30 秒、2 分钟、10 分钟退避重试后再回到 12 小时间隔。
  - 更新发现与“自动安装已下载、退出时安装”的通知改为由 Rust 后端直接发送（同一版本按状态仅提示一次），避免启动阶段的通知在浮窗前端未挂载前丢失。
