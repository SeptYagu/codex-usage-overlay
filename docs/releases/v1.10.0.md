# Codex Usage Overlay v1.10.0

Stable release on top of `v1.9.7`. It adds local quota usage history and includes everything from `v1.10.0-preview.1` through `v1.10.0-preview.3`.

## Added

- **Usage history window.** Open it from the tray menu (**Usage History…**), the overlay's right-click menu, or the **Open usage history** button in Common settings. Pick a provider tab and a range of 24 hours, 7 days, 30 days or 90 days. The window shows:
  - **Usage over time**: used percent of the 5-hour and weekly limits (plus Argon for Antigravity, while agy reports it). Vertical lines mark resets, shaded stretches had no readings, and dashed lines show the protection thresholds when protection is on. Hover, or use the arrow keys, to read exact values.
  - **Daily consumption**: how much of each limit was used per day, with a table view. Several 5-hour windows fit in a day, so the 5-hour bar can exceed 100%. Days that include time without readings are dimmed.
  - **Quota windows**: each past 5-hour and weekly window with its start and reset time, its peak, whether it hit the limit, how long it took to get there, and how much was left unused at reset.
- **Recording.** Every successful read can be recorded in `%LOCALAPPDATA%\CodexUsageOverlay\history\`, one file per provider and month. A reading is written only when it changes, plus once every 30 minutes, so files stay small (a few MB per provider over 90 days). Readings older than 90 days are deleted. Stale snapshots and Claude's display-only expiry projection are never recorded. An account switch starts a new line segment, and account IDs are stored only as a short hash. Nothing is uploaded.
- **Settings.** Common settings add **Record usage history** (on by default) and **Clear history**, which asks for confirmation.

History starts when a `1.10.0` build first runs; earlier usage cannot be reconstructed. History recorded by the previews is kept.

## Fixed during the previews

- **Opening the History window no longer freezes the app** (`v1.10.0-preview.2`). On Windows, a window built from a synchronous command or a menu event handler deadlocks; the window is now built on a worker thread and the history commands run off the main thread.
- **Resets are placed at the provider's reset time** (`v1.10.0-preview.3`). A reset through an unused window is drawn once, at the old window's reset time. Claude's reset times are recorded as whole minutes, so a 21:10 reset no longer shows as 21:09. An unused Codex window no longer records a reset time that moves forward with every read, which also stops it writing a line every minute.

## Known limits and verification

- The History window was looked at by hand in an installed `v1.10.0-preview.3` before this release. The full frontend, Rust, DSH companion, packaging and Claude process-tree checks pass locally on Windows.
- The History window opens centred each time and does not yet remember its size and position.

## 中文说明

`v1.10.0` 正式版基于 `v1.9.7`，新增本机额度用量历史，包含 `v1.10.0-preview.1` 至 `v1.10.0-preview.3` 的全部内容。

### 新增

- **用量历史窗口。** 从托盘菜单、浮窗右键菜单或通用设置中的“打开用量历史”进入。选择来源和时间范围（24 小时、7 天、30 天、90 天），可查看：用量走势（5 小时、每周及 Antigravity 的 Argon 已用百分比，含重置线、无读数时段和保护阈值）、每日消耗（附表格视图）以及历次额度窗口（起止时间、峰值、是否触及上限、到达上限用时、重置时未用额度）。
- **记录。** 读数只在变化时写入，另每 30 分钟写入一次，保存在 `%LOCALAPPDATA%\CodexUsageOverlay\history\`，每个来源每月一个文件，超过 90 天自动删除。不会记录过期快照和 Claude 的显示投影；账号仅以短哈希保存；不会上传任何数据。
- **设置。** 通用设置新增“记录用量历史”（默认开启）和“清除历史”（需确认）。

历史从首次运行 `1.10.0` 版本时开始记录，无法补录此前的用量；预览版已记录的历史会保留。

### 预览期间的修复

- 打开用量历史窗口不再导致应用卡死（`v1.10.0-preview.2`）。
- 重置时间与服务商一致（`v1.10.0-preview.3`）：经过未使用窗口的重置只画一次；Claude 重置时间按整分钟记录；未使用的 Codex 窗口不再记录不断后移的重置时间，也不再每分钟写入一行。

### 验证情况

- 发布前已在安装的 `v1.10.0-preview.3` 上手动查看用量历史窗口；前端、Rust、DSH 助手、打包与 Claude 进程树检查均在本机 Windows 通过。
- 用量历史窗口每次居中打开，暂不记忆窗口大小和位置。
