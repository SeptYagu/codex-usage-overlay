# Codex Usage Overlay v1.9.7

Stable release on top of `v1.9.6`. It includes the fix from `v1.9.7-preview.1` and adapts Antigravity to agy 1.5.9, which no longer reports a separate Argon quota.

## Fixed

- **Antigravity Argon readings follow the Gemini limits.** Since agy 1.5.9, `/usage` lists Gemini 4 Argon and Orchestrator (Argon) inside the Gemini group, which shares the Gemini weekly and five-hour limits, and returns no Argon WTU bucket. With an Argon model under `auto`, or the `argon` pool chosen in settings, WK was blank and low-quota protection had no weekly limit to act on. The Argon pool now uses the Gemini limits when no Argon bucket is reported, so WK, the burn rate and protection work again. With agy 1.5.9 the `argon` pool setting behaves like `gemini`. Older agy versions that still report an Argon bucket keep the separate AR reading.
- **The overlay no longer stays cropped after a remote-desktop virtual display.** When a virtual display (Vibepollo, Sunshine and similar) comes and goes, Windows restores the window to the size it remembered for that layout. If the readings had grown in the meantime, part of the capsule was cut off. The overlay now notices when the window size no longer matches its content and writes the correct size back, and re-checks its size after every display change.
- **The overlay follows the display's real pixel ratio after a DPI change.** WebView2 can apply the new monitor scale after the scale-change event arrives, which left the size correction for Windows text scaling one step behind.

## Known limits and verification

- The full frontend, Rust, DSH companion, packaging and Claude process-tree checks pass locally on Windows. The Argon change is covered by a regression test built from real agy 1.5.9 `/usage` output.
- Not yet checked by hand in the installed package: Argon readings with a live Argon model, and the display fixes with a real Vibepollo virtual-display session.

## 中文说明

`v1.9.7` 正式版基于 `v1.9.6`，包含 `v1.9.7-preview.1` 的修复，并适配不再单独报告 Argon 额度的 agy 1.5.9。

### 修复

- **Antigravity 的 Argon 读数改用 Gemini 额度。** agy 1.5.9 起，`/usage` 把 Gemini 4 Argon 和 Orchestrator (Argon) 列入 Gemini 组，与 Gemini 共用每周和五小时额度，不再返回 Argon WTU 额度。此前在 `auto` 下使用 Argon 模型或在设置中选择 `argon` 配额池时，WK 为空，低额度保护也没有每周额度可判断。现在未报告 Argon 额度时，Argon 配额池改用 Gemini 额度，WK、消耗速率和保护恢复正常；在 agy 1.5.9 下 `argon` 选项与 `gemini` 相同。仍报告 Argon 额度的旧版 agy 保持单独的 AR 读数。
- 远程桌面虚拟显示器（Vibepollo、Sunshine 等）断开后，悬浮窗不再一直被裁掉一截：窗口尺寸与内容不符时会自动重新适配，每次显示器变化后也会重新测量。
- DPI 变化后改为跟随 WebView2 实际的像素比，修正系统文本缩放补偿滞后一步的问题。

### 验证情况

- 前端、Rust、DSH 助手、打包与 Claude 进程树检查均在本机 Windows 通过；Argon 修复有基于 agy 1.5.9 真实 `/usage` 输出的回归测试。
- 尚未在安装版上用实际 Argon 模型和真实 Vibepollo 会话手动验证。
