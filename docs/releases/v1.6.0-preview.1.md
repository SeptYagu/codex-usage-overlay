# Codex Usage Overlay v1.6.0-preview.1

DSH Codex 订阅适配预览版。**DSH 插件读数与本机 Codex 读数严格分开；默认不连接、不暂停，也不自动选择账户或会话。**

## 新功能

- 设置中新增 **DSH** 用量来源，通过选中的 DSH 实例读取 `dsh-codex-subscription` 自有订阅额度，不读取或回退到本机 Codex 登录。
- 实例/账户维度隔离速率、重置与诊断历史；切源、切账户和迟到响应有 generation 防护。
- 可选“额度不足时暂停”，5 小时/每周阈值独立，默认 **0%**。只向明确绑定、仍在运行且路由匹配的普通会话发送一次固定本地化暂停消息，不操作子代理或其他账户。
- 新增轻量 companion，提供 Desktop 的受限 loopback 桥接；不读取或复制 DSH Host/OAuth 密钥。配对密钥只进入 overlay native 内存，不保存到设置或前端。

## 安装与使用

1. 下载并安装本页的 overlay 安装包，或解压便携版；无需卸载稳定版，但不要同时启动两份。
2. 另下载 `dsh-codex-usage-overlay-bridge-0.1.0.tgz`，在目标 DSH 插件管理器添加本机 tarball，按提示在方便时重启 DSH。保持原来的 `dsh-codex-subscription` 启用。本次接口依据订阅插件 3.2.3。
3. overlay 设置 → 用量来源 **DSH** → 发现并明确选择正确实例 → 连接 → 明确选择账户 → 核对额度。
4. 刷新会话，勾选需要保护的普通测试会话，确认后再开启暂停。切换 DSH 当前账户或重启插件/overlay 后，请重新核对或配对。

## 必须了解的限制

- 这是协作式 `steer` 暂停消息，**不是请求层强制拦截或硬中断**。DSH 接收消息不等于模型已经停止；额度完全用尽后，模型可能无法再处理暂停文本。需要时可将阈值设在耗尽之前。
- 不自动继续、不广播。已提交但结果未知的消息不会自动重试，避免重复干扰。
- 会话查询与发送并非原子操作，存在运行状态竞态。未在当前 DSH 中安装或向真实工作会话发消息；真实额度耗尽/暂停和视觉 WebView 验收尚未完成，因此先发预览版。
- 稳定版更新渠道不受影响。想通过 updater 接收此版，需要主动开启“包含预览版本”，也可以从本页手动安装。

Independent DSH Codex subscription provider with explicit instance/account/session selection and isolated quota history. Install the additional companion tarball in DSH, pair in overlay Settings, verify the account, then opt into cooperative pause. It never falls back to the local Codex account. Pause sends a fixed `steer` message, not a hard stop; real-account exhaustion and live delivery remain unverified. This is an opt-in preview, not a replacement for the stable update channel.
