# Codex Usage Overlay v1.8.0

**Stable release / 正式版** — 2026-11-08

## Changes

- Codex, Claude and DSH now have independent Classic, Weighted and experimental Personalized 5H burn-rate selections. Existing Codex settings migrate to the Codex column. A selection change reprojects the cached reading without another quota request or learning event. Weekly estimates and quota protection keep their existing behavior.
- DSH estimation history follows the verified instance and account across transport address changes. Claude's advanced estimates require a valid local account identity; when it is unavailable, the display falls back to Classic and personal learning pauses. Account transitions isolate history.
- Enabling quota rotation no longer adds a source label or reserves the largest candidate size. The current capsule keeps its appearance; an actual source switch resizes it to the new content. Hover shows the source when logos are hidden.
- Corrected the frontend fallback for older settings so Claude and DSH cannot inherit the legacy Codex algorithm choice.

## Validation and limits

Frontend build and 188 tests passed. Edge layout QA passed 296 combinations across the three sources, layouts, languages, themes, logo states and DPI settings. Rust production and test code passed GNU `cargo check`; local Rust test execution was blocked by this machine's Windows GNU linker/runtime, so the tagged MSVC workflow is the release gate for Rust tests and packages.

The Weighted and Personalized options share the Codex estimator logic, but forecast accuracy on live Claude and DSH accounts has not been measured here. No Claude Code account or DSH Host was available for a live provider check. Native installed-window, mixed-monitor docking and real account-switch checks remain separate acceptance work. Missing verified identity leaves the advanced Claude estimates unavailable rather than mixing account histories.

- Codex、Claude、DSH 各自保存 5 小时消耗速率的经典、加权、个性化（实验性）选择。原 Codex 选择迁移到 Codex 栏；切换只重投影缓存，不额外请求额度或训练。每周预测与额度保护维持原规则。

- 修复旧设置在前端投影时让 Claude／DSH 继承 Codex 算法的问题。

前端构建、188 项测试和 296 组 Edge 外观组合通过。Rust 代码检查通过；本机 GNU 链接／运行环境无法执行完整 Rust 单测，正式标签工作流的 MSVC 测试和打包结果才是发布门槛。Claude 与 DSH 的真实账户预测精度、安装版窗口及多屏贴边仍需实机验证。
