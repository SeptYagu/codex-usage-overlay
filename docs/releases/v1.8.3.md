# Codex Usage Overlay v1.8.3

**Stable bugfix release / 正式修复版** — 2026-11-08

## Fix

DSH `session/list` now sends its required `_request` argument. The bridge validates and forwards the same shape, fixing the upstream error that prevented the settings page from listing sessions and was previously shown as an automatic connection failure. The overlay also upgrades a selected, older bridge installed in its own managed package directory through DSH Desktop's official plugin CLI. Disabled and custom installed bridges are not changed. If DSH does not hot reload the upgraded plugin, restart DSH normally to load it.

The v1.8.2 workflow was cancelled before publication when this protocol mismatch was discovered. Its tag remains in Git history; v1.8.3 supersedes it.

## Validation and limits

GitHub Windows CI must pass for this source commit before tagging. The tagged Release workflow builds and signs the NSIS, MSI and portable packages. On the affected machine before this fix, DSH subscription status and usage requests succeeded but `session/list` returned an upstream error. A live installed-package check of v1.8.3 is still pending.
