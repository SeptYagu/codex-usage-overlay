# Codex Usage Overlay 1.8.4

Fix a serious Windows tray icon leak. The affected running instance accumulated 934 hidden tray windows, and its notification area filled with duplicate quota rings.

Quota updates now keep the existing tray resource, native window and icon identity. Recovery re-registers that same icon through its own taskbar-recovery handler; it never replaces the resource or broadcasts recovery to other applications. Updates and recovery run together on the Windows owner thread, with the existing 30-second retry limit.

## Validation and limits

Local Windows validation passed: frontend production build and 188 tests; 499 Rust tests (9 intentionally ignored); 16 bridge tests; packaging regressions and the affine parity fixture. The regression suite covers 10,000 consecutive failed updates, recovery retry boundaries and repainting after the shell returns. The separately executed interactive Windows test also passed: 100 native recovery cycles retained the same window handle and exactly one tray window, and owner-thread teardown returned the window count to baseline. This interactive test is excluded from normal headless CI.

GitHub Windows CI must succeed for the source commit before tagging. Official signed NSIS, MSI and portable packages are built by the tagged Release workflow. Installed-package verification and removal of icons left by the previously running version remain pending until the affected copy is updated; this release does not scan or remove other applications' notification icons.

## 中文说明

修复严重的系统托盘图标泄漏：受影响实例积累了 934 个隐藏托盘窗口，通知区域出现大量重复额度圆环。

额度刷新和恢复现在统一在 Windows 窗口所属线程执行。恢复只重新注册原来的图标和窗口，不再删除并新建托盘对象，并保留 30 秒重试间隔。恢复后会写入最新额度和提示文字。

本机已通过前端构建及 188 项测试、499 项 Rust 测试（另有 9 项按设计跳过）、16 项桥接测试、打包回归和仿射一致性检查。新增回归覆盖连续 10,000 次失败、重试边界和恢复后的刷新；单独运行的交互式 Windows 检查也已通过：重复恢复 100 次仍为同一个托盘窗口，并可在所属线程正常释放。发布前须通过目标提交的 GitHub Windows CI；正式包由 Release 工作流构建并签名。受影响安装版更新及旧版遗留图标清理仍待实机验收。
