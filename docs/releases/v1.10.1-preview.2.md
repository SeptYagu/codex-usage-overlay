# Codex Usage Overlay v1.10.1-preview.2

This preview changes the Usage history timeline to show **remaining quota percent**.

## Changed

- The 5-hour, weekly and Antigravity Argon lines descend as quota is used and rise after a reset. The vertical axis reads 100% at the top and 0% at the bottom. Hover and keyboard readouts, isolated points and protection threshold lines use the same remaining-quota scale.
- Missing readings and gaps stay missing. Daily consumption, quota-window statistics, recorded history and protection behavior keep their existing meanings and values. No history migration or new setting is needed.

## Verification and limits

- All 214 frontend tests and the production build pass locally, including timeline geometry, reset breaks, missing readings, readouts and threshold positions. Local Rust tests could not link because MSVC `link.exe` is absent; Windows CI is the release gate for both x64 and ARM64.
- The chart has not yet been checked in an installed package on both light and dark themes. ARM64 installers and MSI still need a native ARM64 installation check.

## Included assets

- x64 and ARM64 NSIS installers and MSI packages, each with its updater signature
- x64 and ARM64 portable ZIP archives, each with its updater signature
- `dsh-codex-usage-overlay-bridge-0.1.2.tgz` (unchanged)
- `latest.json` and `SHA256SUMS.txt`

Enable **Include preview releases** in Settings to receive this prerelease.
