# Codex Usage Overlay v1.6.0-preview.2

## Clearer settings and working edge-bar grids

- Settings now explain how edge auto-hide works: drag the overlay to a screen edge, then move the pointer away to collapse it into small quota bars. Hover over the bars to expand it.
- **Show 10% grid on edge bars** appears only when **Auto hide at screen edge** is enabled. Its description explains where the grid appears and how to show it. Turning edge auto-hide off preserves your grid preference.
- Added or improved descriptions for layout, transparency, 5-hour quota visibility, burn rate, click-through, usage sources and refresh cadence in **English, Simplified Chinese and Traditional Chinese**, with accessible description associations.
- Fixed transparent empty quota tracks and clipping of docked bars above 100% scale. Expanded-window sizing now reserves space for the provider logo during hover expansion.

## Installation and preview channel

Install an NSIS/MSI package or extract the portable ZIP. Enable **Include preview releases** to receive this version through the updater; the stable update channel remains on the stable release.

DSH support from preview.1 is included. The companion remains `dsh-codex-usage-overlay-bridge-0.1.0.tgz`; existing preview.1 users do not need a new companion. See the [DSH setup guide](https://github.com/SeptYagu/codex-usage-overlay/blob/v1.6.0-preview.2/docs/dsh-subscription.md).

## Validation and limits

Local checks passed: **156 frontend tests**, TypeScript/Vite production build, **415 main-library + 10 helper Rust tests** (7 existing ignored), **15 companion tests**, companion packaging and **7 packaging regression cases**. **634 general UI + 768 percentage-grid Edge checks** passed. They cover translated Settings at 960×620 and 760×500 and percentage grids on every edge in both themes, at 100%/175%/250% scale and device scale factors 1 and 1.75. The release workflow repeats the frontend, Rust, companion and packaging gates before publishing signed updater assets.

Browser checks use production React/CSS with offline native effects. Native WebView2 window sizing, mixed-monitor hover behavior, installed-package smoke checks and real DSH pause delivery have not been verified for this preview. DSH pause remains cooperative; accepted delivery does not prove inference stopped. This prerelease does not change protection defaults or enable automatic resume.

- 设置新增或改进浮窗布局、背景透明度、5 小时额度、消耗速度、鼠标穿透、用量来源、刷新间隔和贴边行为的说明，完整支持**英文、简体中文和繁体中文**，并为辅助技术关联控件说明。
