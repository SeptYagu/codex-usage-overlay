# Codex Usage Overlay v1.7.0

**Stable release / 正式版** — 2026-11-07

## Independent provider settings

- Codex, Claude and DSH each have a fixed settings column, with independent monitoring, refresh intervals, protection thresholds, reset notifications and sound preferences. Appearance and update options remain in a collapsible common section.
- Existing preferences migrate to schema 3 without clearing histories or enabling new protection. Audio previews are correlated to their provider and playback request so late replies cannot stop another preview.

## Codex pause messages and burn-rate estimates

- Edit separate 5-hour and weekly pause messages, up to 2,000 UTF-16 units. Weekly takes priority when both quota limits trigger. Language changes preserve saved custom text; missing defaults follow the saved language.
- The optional scheduled-continuation template inserts one absolute target time: the quota reset plus 120 seconds, including date, UTC offset and system time zone. The receiving chat creates and verifies its task; the overlay does not create a task itself. Its wake-up instructions require disabling the task before continuing. Invalid time information falls back to a pure pause request.
- Successful or possibly submitted requests are not blindly resent within the same account/chat/quota cycle. Unknown results are shown explicitly; editing text or toggling protection does not erase the cycle record. Triggers without a reset timestamp release their temporary keys rather than blocking unrelated future cycles.
- Choose Classic (default), Weighted or Personalized (experimental) for the Codex 5H burn-rate display. Missing estimates fall back to available candidates. Selection reprojects the cache without extra quota reads, learning or protection actions; Weekly keeps its existing estimator. Personal calibration does not guarantee greater accuracy.

## Automatic quota rotation

- Rotation is off by default. Select participating providers in their columns and use the interval slider: **3–30 seconds**, one-second steps, default **8 seconds**.
- Only enabled, selected providers with usable, fresh cached data participate. Temporary failures can retain a fresh reading; authentication failures and expired data remove a provider. Fewer than two eligible providers means standby.
- Hover, keyboard focus, dragging, menus, hiding, minimizing and a collapsed dock pause rotation. Resuming starts a full interval; manual selection holds for 30 seconds. Automatic switches do not write settings, fetch quota or alter protection. Turning rotation off keeps the visible provider.
- Overlay, tray, refresh actions and displayed protection summaries follow the same current provider. Source text remains visible even with logos hidden, and candidate measurements reserve stable capsule dimensions. Source identities and display revisions reject stale or mismatched events.

## Packages and validation limits

Windows x64 NSIS, MSI and portable ZIP packages are produced by the release workflow, with updater signatures, `latest.json` and `SHA256SUMS.txt`. Both stable and preview installations can update to v1.7.0 without enabling preview releases.

The source milestone passed frontend tests/build, Rust main-library/helper tests, DSH offline tests, packaging regressions, 96 synthetic cross-language estimator cases and 1,086 Edge display combinations. The latest pre-release-preparation commit also passed GitHub CI; the tagged release workflow repeats tests and builds the packages. Synthetic model parity verifies implementation consistency, not forecast accuracy.

Native installed-window interactions, mixed-monitor DPI/docking, real audio and live chat/task wake-up acceptance have not been completed in this release preparation. Cooperative delivery acknowledgement does not prove a chat stopped or a scheduled task was created. Turning protection off does not cancel tasks already created by chats. These limits are not counted as passing checks.

## 中文说明

- **独立设置三栏**：Codex／Claude／DSH 各自保存监控、刷新频率、保护阈值、重置提醒和音效。公共外观、更新设置单独折叠；升级保留旧偏好和历史，不自动开启新保护。
- **Codex 暂停文案**：5 小时与每周分别编辑，同时触发时每周优先；语言变化不覆盖已保存文字，缺失默认文案按保存语言补全。同账号／聊天／额度周期的成功或未知投递不盲目重发，未知回执可见；无重置时间的触发不会遗留阻塞未来周期的临时键。
- **指定时间继续模板**：主动应用模板后，浮窗自动计算重置时间＋120 秒，向聊天提供带完整日期、偏移及时区的单一指定时间。目标聊天创建并核验任务，唤醒后先停用自身再继续；时间无效时退回纯暂停。浮窗不直接创建任务，关闭保护也不会取消聊天已创建的任务。
- **可选消耗速率算法**：Codex 5H 可选经典、加权、个性化（实验性），缺少候选时明确回退。切换只重投影缓存，不额外读额度、训练或触发保护；每周算法不变。
- **额度轮播**：默认关闭，各来源独立勾选，间隔为同风格 **3–30 秒滑块**、步长 1 秒、默认 8 秒。只使用已监控且新鲜有效的读数，不额外读取或更改保护；手动选择停留 30 秒，交互及隐藏／收起时暂停。关闭轮播保留当前页，隐藏 logo 仍显示来源文字。
- **v1.7.0 正式版**，稳定版及预览版均可更新。发布流程生成 NSIS、MSI、便携 ZIP、更新签名及校验值；实际原生窗口／多屏／音效／聊天暂停和定时唤醒尚未完成验收，详情见上文。
